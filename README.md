# Ruby Web Test Automation — Selenium, Capybara & Cucumber

A collection of practical exercises and web test automation examples developed with **Ruby**, **Selenium WebDriver**, **Capybara**, and **Cucumber**.

The repository documents my early work with browser automation and demonstrates the evolution of test scenarios from language fundamentals to end-to-end Web automation.

## Technologies

- Ruby
- Selenium WebDriver
- Capybara
- Cucumber
- Gherkin

## Repository structure

```text
starter-sellenium-e2e/
├── Exercícios/          # Ruby programming exercises
├── Ruby for QA/         # Ruby concepts applied to quality engineering
├── Web-Automation/      # Browser automation examples
└── README.md
```

## Topics demonstrated

- Browser interaction and element location
- Scenario organization with Gherkin
- End-to-end test execution
- Reusable automation steps
- Ruby fundamentals for test automation

## Note

The repository name uses the legacy spelling `sellenium`. The correct framework name is **Selenium**. Renaming the repository to `ruby-selenium-capybara-e2e` is recommended for a clearer professional presentation.
